# スマートフォンからの入力

勤怠は画面上部で従業員・日付・出勤・退勤・休憩時間を入力して記録します。
出勤ボタンで時刻を記録するリアルタイム打刻機能ではありません。
登録済み勤怠はスマホでは日別のカードになり、編集して保存できます。
納品書は上部の「納品書入力」から作成します。枚数・戻し・その他商品・調整の計算はPCと共通です。

## 外出先からの接続（初回設定が必要）

アプリにログイン機能がないため、インターネットに直接公開せず、ご本人の端末のみのTailscaleネットワーク内で利用します。

1. Macとスマートフォンに公式Tailscaleアプリをインストールします。
2. 両方で同じ個人アカウントにログインし、OSのVPN設定を許可します。
3. アカウントの参加端末が自分の端末だけであることを確認します。他の利用者や端末を招待・共有しないでください。
4. MacでDockerとアプリを起動し、localhostで表示を確認します。
5. 初回接続設定ではTailscale ServeのHTTPS転送先をlocalhostのアプリポートに設定します。Funnel（一般公開）は使用しません。
6. HTTPS転送時は、確認した転送元IPのみを `.env` の `TRUSTED_PROXIES` に設定し、設定キャッシュをクリアします。Laravelはその転送元のHTTPSヘッダーだけを信頼します。接続情報はGitに含めません。Dockerネットワークを作り直してIPが変わった場合は再確認してください。
7. iPhoneのWi-Fiを切り、携帯回線＋Tailscaleでアクセスし、画面・保存・リダイレクトを確認します。

初回設定後は、外出先からの実機確認を行ってください。Macの画面消灯は問題ありませんが、本体のスリープ中やDocker停止中は接続できません。
Androidへの機種変更時もTailscaleの再設定後、ブラウザで利用できます。

公式資料: https://tailscale.com/docs/reference/tailscale-cli/serve
