# Solo Backoffice — 木材加工業向け業務管理アプリ

木材加工業の個人事業で行う、納品・請求・入金・勤怠・給与・帳簿作成をまとめて管理するWebアプリです。Laravelで開発しました。

## 制作背景・目的

現場での業務をもとに、同じ内容を複数の帳簿へ転記する手間や、日付・金額の入力ミスを減らすことを目的に制作しました。木材の寸法や数量による単価計算、加工せず返却する「戻し」の枚数管理など、業務に合わせた機能を実装しています。

入金と給与支払いの登録を振替伝票へ連携し、その仕訳を出納帳・総勘定元帳・決算書で確認できる構成にしています。

## 公開版について

実業務向けに開発したアプリの公開版です。個人情報・実際の取引データは含みません。実運用環境とは独立して起動できます。

- 実際の取引先・従業員・事業者情報・取引・給与・期首残高は含みません。
- 実運用の接続情報・印影・出力PDF・過去のGit履歴は含みません。
- 初期データは共通の勘定科目と2025・2026年の源泉徴収税額表のみです。
- 取引先や単価などは、起動後に画面から登録します。テスト内の値は架空のデータです。

## 主な機能

| 分類 | 機能 |
| --- | --- |
| マスタ管理 | 事業者情報、取引先、適格請求書発行事業者登録番号、品目、単価、従業員、勘定科目、支払先の管理 |
| 納品・請求 | 木材の寸法・数量による単価計算、単価調整、内容付きの金額調整、戻し枚数、月次請求書、PDF出力 |
| 勤怠管理 | 個人別・月別の勤怠表示、勤務時間と日給の計算、給与明細PDF |
| 給与支払い | 従業員・専従者の区分、扶養人数に応じた源泉徴収、市県民税控除、差引支給額の計算 |
| 入金管理 | 現金・銀行振込による入金登録と振替伝票への反映 |
| 会計 | 振替伝票、現金・銀行預金出納帳、総勘定元帳、期首残高の管理 |
| 決算書 | 損益計算書・貸借対照表の表示、各1ページのPDF出力 |
| 入力チェック | 必須項目・日付・金額の検証、勤怠や給与の重複防止、使用中マスタの削除防止 |

## 工夫した点

- **転記作業の削減**：入金・給与支払いから仕訳を作成し、帳簿に反映します。一般の支出は振替伝票へ直接入力します。
- **入力ミスの防止**：振替伝票は対象年月と日付の整合性をチェックし、勤怠は同じ従業員・同じ日の重複登録を防ぎます。サーバー側でも入力値を検証します。
- **修正のしやすさ**：帳簿から振替伝票の編集画面を開き、保存後は編集元の画面へ戻れます。
- **PDFの読みやすさ**：請求明細の表見出しを整理し、総勘定元帳は少ない明細をまとめて配置して「現在ページ／総ページ数」を表示します。

## 環境構築

### 1. 事前準備

Git、Docker Desktop（起動済み）、Composer、`composer.lock`の要件を満たすPHPが必要です。`composer.json`のPHP指定は`^8.2`で、アプリ実行用のSailコンテナはPHP 8.5を使用します。

以下はmacOS／Linux、またはWindowsのWSL2内で実行してください。

### 2. リポジトリを取得

```sh
git clone https://github.com/AliettaA/solo-backoffice.git
cd solo-backoffice
cp .env.example .env
```

`.env`の`DB_PASSWORD`をローカル開発用の任意のパスワードに変更します。実運用版の`.env`やDBはコピーせず、公開版を取得したフォルダ内で以降のコマンドを実行してください。

### 3. 依存パッケージのインストールと起動

```sh
composer install
./vendor/bin/sail up -d
./vendor/bin/sail artisan key:generate
./vendor/bin/sail artisan migrate
./vendor/bin/sail artisan db:seed
./vendor/bin/sail artisan storage:link
```

初回起動時はコンテナのビルドに時間がかかります。DB接続エラーが出た場合は、MySQLの起動完了を待ってから`migrate`を再実行してください。

画面はTailwind CSSのCDNと配信済みのJavaScriptを使用しているため、通常の動作確認に`npm run dev`は不要です。画面のスタイル表示にはインターネット接続が必要です。

### 4. アクセス

| 用途 | URL |
| --- | --- |
| アプリ | http://localhost:8088 |
| phpMyAdmin | http://localhost:8089 |

認証機能は未実装のため、ログイン操作やテスト用アカウントはありません。アプリを開くと取引先一覧を表示します。

公開版の開発環境のComposeプロジェクト名は`ohtaworks_school`、DB名は`school_app`、ホスト側のDBポートは`3308`です。実運用版とDBボリュームを分離しています。別環境には同じComposeプロジェクト名を指定しないでください。

ポートが使用中の場合は、`.env`の`APP_PORT`、`FORWARD_DB_PORT`、`FORWARD_PHPMYADMIN_PORT`を変更してください。アプリのポートを変更した場合は`APP_URL`も合わせて変更します。

### 既存環境での更新

旧見積・請求機能を整理する場合は、DBのバックアップを取得してから`./vendor/bin/sail artisan migrate`を実行してください。旧5テーブルに1件でもデータがある場合は、何も削除せず処理を中止します。現行の納品・入金・給与・仕訳データは削除対象に含みません。

### 停止・再開

```sh
# 停止（DBデータは保持）
./vendor/bin/sail stop

# 再開
./vendor/bin/sail up -d
```

## 初回登録と動作確認の流れ

業務データは空の状態で起動します。架空の情報を使い、次の順番で確認できます。

1. **マスタ登録**：事業者情報と取引先を登録します。木材明細を使う場合は単価マスタの樹種・幅単価・数量帯などを設定します。品目を登録し、品目のみの明細を作成することもできます。
2. **納品・請求**：納品書を作成し、明細・調整額・合計金額とPDFを確認します。月次請求書では取引先と対象年月を選択します。
3. **入金**：入金管理で入金を登録し、振替伝票と支払方法に対応する出納帳への反映を確認します。
4. **勤怠・給与**：従業員の区分・時給・扶養人数を登録し、勤怠を入力します。月間集計を確認後、給与支払いを登録して仕訳と出納帳を確認します。
5. **帳簿・決算**：必要に応じて期首残高と支出の振替伝票を入力し、出納帳・総勘定元帳・決算書を確認します。

給与の確認には、税額表を収録している2025年または2026年の支払日を使用してください。勤怠の集計を表示しただけでは給与支払いの登録・仕訳作成は行われません。

## テスト

```sh
# 全テスト
./vendor/bin/sail test

# 給与計算・仕訳連携
./vendor/bin/sail test --filter=PayrollTest

# 業務入力のバリデーション
./vendor/bin/sail test --filter=BusinessValidationTest
```

給与計算、入金と仕訳の連携、単価・調整額、決算書、入力チェックなどを検証するテストを用意しています。業務機能のテストはSQLiteのメモリ上に検証用テーブルを作成します。MySQL専用のマイグレーションもあるため、アプリ本体にはMySQLを使用してください。

## 現在の対応範囲

- 個人事業での利用を想定した帳簿・決算書です。
- 専従者給与は月額80,000円、従業員給与は勤怠に保存した給与額の月合計を使用します。
- 源泉徴収の実装対象は2025・2026年の月額表・甲欄、扶養親族等0〜7人、社会保険料等控除後332,000円未満です。対象外はエラーを表示します。
- 市県民税は入力額を源泉徴収額とは別に控除します。社会保険料の自動算定、乙欄、賞与、年末調整、給与の分割払いには対応していません。
- 認証・権限管理は未実装です。現状はローカル環境での利用を想定しています。

給与の計算条件と仕訳の詳細は[給与・源泉徴収の設定](docs/payroll.md)を参照してください。

## フォント・データの取り扱い

PDF用のIPAexゴシックは、[IPAフォント公式配布ページ](https://moji.or.jp/ipafont/ipafontdownload/)のフォントをライセンス・READMEとともに`resources/fonts/`へ同梱しています。

`.env`、DBファイル、ログ、アップロード、PDF、バックアップ、生成済みフォントキャッシュ、`vendor`、`node_modules`はGitの管理対象から除外しています。公開リポジトリには実運用のデータや履歴を取り込まないでください。
